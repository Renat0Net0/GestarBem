# Controle de Configuração — GestarBem

## Objetivo

O controle de configuração tem como objetivo manter organizados e
rastreáveis os artefatos produzidos durante o desenvolvimento do
GestarBem.

## Itens controlados

Serão controlados:

- Código-fonte;
- Documentação;
- Scripts do banco de dados;
- Casos de teste;
- Diagramas;
- Arquivos de configuração;
- Versões do sistema.

## Controle de alterações

As alterações serão registradas por meio de:

- Commits;
- Branches;
- Pull Requests;
- Issues.

## Rastreabilidade

Cada funcionalidade deverá estar relacionada, quando aplicável, a:

Requisito
↓
Issue
↓
Branch
↓
Commit
↓
Pull Request
↓
Teste

## Responsabilidade

Os integrantes do projeto serão responsáveis por registrar corretamente
as alterações realizadas e manter os artefatos do projeto organizados.
